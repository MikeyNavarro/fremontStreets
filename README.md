## Getting started

Clone the repository and enter its directory:

```sh
git clone https://github.com/MikeyNavarro/fremontStreets.git
cd fremontStreets
```

In the Codex cloud environment, use the existing checkout at `/workspace/fremontStreets`.

There are currently no installation, startup, or test commands. Add those instructions here as the project develops.
